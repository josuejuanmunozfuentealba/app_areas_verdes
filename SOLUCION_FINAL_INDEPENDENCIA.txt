┌─────────────────────────────────────────────────────────────────────────────┐
│  PROBLEMA: "Servidor no disponible"                                         │
└─────────────────────────────────────────────────────────────────────────────┘

  Paso 1: Verifica si Python está instalado
    CMD> python --version
    
    Si no funciona: Instala Python desde https://www.python.org

  Paso 2: Inicia el servidor
    Doble clic en: iniciar_servidor.bat

  Paso 3: Verifica que está corriendo
    🌐 http://localhost:3000/api/health
    
    O ejecuta: probar_servidor.bat

  Paso 4: Si el puerto está ocupado
    CMD> netstat -ano | findstr :3000
    CMD> taskkill /PID <numero> /F


┌─────────────────────────────────────────────────────────────────────────────┐
│  PROBLEMA: Descargas no funcionan                                           │
└─────────────────────────────────────────────────────────────────────────────┘

  Verifica:
    1. ¿Estás en un navegador web? (Chrome, Edge, Firefox)
    2. ¿El navegador permite descargas?
    3. ¿Hay espacio en disco?

  Nota: Las descargas NO requieren servidor, funcionan localmente en el
  navegador. Si no funcionan, revisa la consola del navegador (F12).
