EL PROBLEMA REAL:
-----------------
❌ El servidor Python tenía un ERROR DE PROTOCOLO HTTP
❌ Enviaba headers HTTP duplicados (mal formateados)
❌ Error: "CR debe ir seguido de LF"
❌ Chrome no podía cargar la página por este error

LA CAUSA:
---------
En servidor.py, el método do_GET() estaba:
1. Enviando headers manualmente (send_response, send_header)
2. Luego llamando a super().do_GET()
3. Que enviaba headers OTRA VEZ
4. Resultado: Headers duplicados = Error de protocolo HTTP

LA SOLUCIÓN:
------------
✅ Eliminé los headers duplicados en servidor.py
✅ Ahora solo llama a super().do_GET() para archivos estáticos
✅ El servidor responde correctamente con StatusCode 200
✅ Chrome puede cargar la aplicación sin errores
