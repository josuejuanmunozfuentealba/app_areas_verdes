┌─────────────────────────────────────────────────────────────────────────────┐
│  PROBLEMA: Descargas no funcionan                                            │
└─────────────────────────────────────────────────────────────────────────────┘

  Verifica:
    1. ¿Estás usando un navegador web? (Chrome, Edge, Firefox)
    2. ¿El navegador permite descargas?
    3. ¿Hay espacio en disco?

  Si el problema persiste:
    • Revisa la consola del navegador (F12)
    • Busca errores de JavaScript


┌─────────────────────────────────────────────────────────────────────────────┐
│  PROBLEMA: Servidor de correos no responde                                   │
└─────────────────────────────────────────────────────────────────────────────┘

  Paso 1: Verifica que Node.js está instalado
    CMD> node --version
    
    Si no funciona: Instala Node.js desde https://nodejs.org

  Paso 2: Verifica el servidor
    CMD> cd email_server
    CMD> node server.js
    
    Deberías ver:
      ✅ El servidor está escuchando en el puerto 3000

  Paso 3: Prueba la conexión
    Abre navegador: http://localhost:3000/api/health

  Paso 4: Si el puerto está ocupado
    CMD> netstat -ano | findstr :3000
    CMD> taskkill /PID <numero> /F


┌─────────────────────────────────────────────────────────────────────────────┐
│  PROBLEMA: Correo no se envía (servidor activo)                             │
└─────────────────────────────────────────────────────────────────────────────┘

  Verifica:
    1. Credenciales de Gmail en email_server/.env
    2. Contraseña de aplicación correcta
    3. Verificación en dos pasos activada en Gmail
    
  Lee: email_server/DIAGNOSTICO.md para más detalles
