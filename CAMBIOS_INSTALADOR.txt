SOLUCIÓN DE PROBLEMAS:
======================

PROBLEMA: "Python no detectado" pero Python SÍ está instalado
SOLUCIÓN: 
  1. Abra CMD y escriba: python --version
  2. Si no funciona, Python no está en el PATH
  3. Reinstale Python y marque "Add Python to PATH"
  4. O agregue Python al PATH manualmente

PROBLEMA: La ventana de precarga aparece vacía (sin logo)
SOLUCIÓN:
  1. Verifique que la carpeta assets\ se instaló correctamente
  2. Debe contener: logoprecarga.png, spinner.gif.gif, iconoescri.ico
  3. Si faltan, reinstale la aplicación

PROBLEMA: Chrome no se abre
SOLUCIÓN:
  1. Verifique que Chrome está instalado
  2. Intente abrir Chrome manualmente
  3. Si Chrome está en una ubicación no estándar, edite precarga.hta
     y cambie "chrome" por la ruta completa a chrome.exe

PROBLEMA: Error "No se puede conectar al proxy"
SOLUCIÓN:
  1. Esto significa que el servidor Python no se inició
  2. Abra CMD en la carpeta de instalación
  3. Ejecute: python servidor.py
  4. Si hay error, verifique que Python está instalado correctamente
