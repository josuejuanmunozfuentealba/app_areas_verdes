PROBLEMAS RESUELTOS:
-------------------

1. ✅ SERVIDOR NO INICIA AUTOMÁTICAMENTE
   - Solución: Cambió de usar batch files complejos a ejecutar pythonw directamente
   - precarga.hta ahora ejecuta: "pythonw servidor.py" (sin ventana)
   - Si pythonw falla, intenta con "python" normal
   - Tiempo de espera aumentado a 4 segundos
   - Reintentos aumentados a 15 intentos

2. ✅ CHROME CARGA VERSIÓN ANTIGUA (CACHÉ)
   - Solución: Chrome ahora se abre con flags especiales:
     * --disable-cache
     * --disable-application-cache
     * --disk-cache-size=1
   - Timestamp agregado a la URL: http://localhost:8080?v=20260115123045
   - Incluye herramienta "Limpiar Cache de Chrome" en el menú

CÓMO INSTALAR EN PC 2:
----------------------

PASO 1: DESINSTALAR VERSIÓN ANTERIOR
   - Panel de Control > Programas y características
   - Buscar "Áreas Verdes Doñihue"
   - Desinstalar

PASO 2: LIMPIAR CACHÉ DE CHROME (IMPORTANTE)
   Opción A - Manual:
   - Abrir Chrome
   - Presionar Ctrl + Shift + Delete
   - Seleccionar "Desde siempre"
   - Marcar "Imágenes y archivos en caché"
   - Borrar datos
   - Cerrar Chrome

   Opción B - Automático:
   - Ejecutar: limpiar_cache_chrome.bat

PASO 3: INSTALAR v12.7
   - Ejecutar: AreasVerdesDoñihue_Setup_v12.7.exe
   - Seguir el asistente
   - Marcar "Crear icono en el escritorio"

PASO 4: PRIMERA EJECUCIÓN
   - Doble clic en el icono del escritorio
   - Debe aparecer ventana de precarga
   - Mensajes: "Iniciando servidor..." → "Esperando servidor..." → "Abriendo aplicacion..."
   - Chrome se abre automáticamente
   - Verificar badge: "Version 12.7 © 2026 Josue_Muñoz"

HERRAMIENTAS DE DIAGNÓSTICO:
----------------------------

En Menú Inicio > Áreas Verdes Doñihue:

1. Áreas Verdes Doñihue
   - Ejecuta la aplicación normalmente

2. Diagnosticar Problemas
   - Verifica Python, Chrome, archivos, servidor
   - Detecta alias de Microsoft Store
   - Intenta iniciar servidor de prueba

3. Limpiar Cache de Chrome (NUEVO)
   - Cierra Chrome automáticamente
   - Elimina todo el caché
   - Soluciona problemas de versión antigua

ARCHIVOS DE LOG:
---------------

Después de ejecutar, revisar en la carpeta de instalación:
- servidor_log.txt (muestra qué Python se usó y errores)

Ubicaciones posibles:
- C:\Program Files\AreasVerdesDoñihue\
- C:\Users\[USUARIO]\AppData\Local\Programs\AreasVerdesDoñihue\

SI SIGUE SIN FUNCIONAR:
-----------------------

1. Ejecutar "Diagnosticar Problemas" desde el menú
2. Copiar TODO el resultado
3. Revisar servidor_log.txt
4. Verificar que Python real está instalado (no alias de Microsoft Store)

SOLUCIÓN RÁPIDA PARA CACHÉ:
---------------------------

Si la aplicación carga versión antigua:
1. Ejecutar la aplicación
2. Cuando se abra Chrome, presionar: Ctrl + Shift + R
3. Esto fuerza recarga sin caché

O mejor:
1. Menú Inicio > Áreas Verdes Doñihue > Limpiar Cache de Chrome
2. Ejecutar la aplicación normalmente
